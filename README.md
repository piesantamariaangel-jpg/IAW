# IAW

##Activitat 4: Creació de l'entorn Docker amb LAMP
- l'Activitat 4 té objectiu crear un entorn LAMP amb contenidors Docker a un servidor Debian i poder accedir a una web i BBDD al navegador.

##Requisits per desenvolupar l'entorn
- Un servidor Debian amb Docker instal·lat i en correcte funcionament.

##Passos realitzats
- Actualitzar el sistema i instal·lar les dependencies de Docker
- Crear un repositori per la ClauGPG i descarregar-la
- Instal·lar Docker
- Crear l'estructura de carpetes del projecte i configurar els tres contenidors
- Editar l'arxiu .yml definint cada contenidor
- Editar l'arxiu index.php i definir el missatge "Hola Món!"
- Activar els contenidors i comprovar l'accés als serveis
